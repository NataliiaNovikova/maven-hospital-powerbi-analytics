# Maven Hospital Healthcare Analytics | Power BI Dashboard

## 📌 Опис проєкту (Project Overview)
Цей проєкт присвячений комплексній аналітиці медичних та операційних показників мережі клінік **Maven Hospital**. Головна мета — надати керівництву клініки та медичному персоналу інтерактивний інструмент для моніторингу завантаженості відділень, аналізу вартості лікування, демографії пацієнтів та ефективності надання послуг.

## 📐 Модель даних (Data Model)

![Data Model Star Schema](screenshots/data_model.jpg)
* **Архітектура:** Модель побудована за схемою **«Зірка» (Star Schema)**[cite: 1].
* **Зв'язки:** Налаштовано односпрямовані зв'язки **1-до-багатьох (1-to-many)** між таблицями вимірів (Dimensions) та таблицями фактів (Facts)[cite: 1].
* **Оптимізація:** Включено спеціальну календарну таблицю для коректної роботи Time Intelligence функцій DAX[cite: 1].

## 📸 Візуалізації та структура дашборду (Dashboard Pages)

### 1. Загальний огляд (Executive Summary)
![Executive Summary](screenshots/executive_summary.jpg)
* **Головні KPI:** Ключові операційні та фінансові показники клініки[cite: 1].
* **Аналіз страхового покриття:** Розподіл витрат та виплат між пацієнтами та страховими компаніями[cite: 1].
* **Гендерний аналіз відвідуваності:** Динаміка та обсяги візитів пацієнтів у розрізі статі (чоловіки/жінки)[cite: 1].

---

### 2. Клінічний аналіз (Clinical Analysis)
![Clinical Analysis](screenshots/clinical_analysis.jpg)
* **Причини звернень та процедури:** Аналіз найпопулярніших медичних аналізів, діагнозів та причин візитів[cite: 1].
* **Матриця відвідуваності («Календар візитів»):** Теплова карта завантаженості клініки по днях тижня та роках (за обраний період)[cite: 1].
* **Загальна динаміка візитів (2011–2022):** Інтерактивна матриця з можливістю деталізації (Drill-down) за роками, кварталами та місяцями[cite: 1].

---

### 3. Демографія пацієнтів (Patient Demographics)
![Patient Demographics](screenshots/patient_demographics.jpg)
* **Соціально-демографічний профіль:** Розподіл пацієнтів за віковими групами, расовою приналежністю (Hispanic / Non-Hispanic) та сімейним станом[cite: 1].
* **Географічний та соціальний контекст:** Дослідження структури пацієнтів для оптимізації соціальних та медичних програм клініки[cite: 1].

---

### 4. Деталізація по пацієнтах (Patient Details)
![Patient Details](screenshots/patient_details.jpg)
* **Показники смертності:** Ключові KPI щодо кількості пацієнтів, їх статусу (живий/померлий) та рівня смертності (% mortality rate)[cite: 1].
* **Повний реєстр візитів:** Детальна таблиця зі списками пацієнтів, датами звернень та супровідною медичною інформацією[cite: 1].

## 🛠 Технологічний стек (Tech Stack)
* **BI Інструмент:** Power BI Desktop[cite: 1]
* **Трансформація даних:** Power Query (M-Language)[cite: 1]
* **Моделювання даних:** Схема «Зірка» (Star Schema), зв'язки 1-до-багатьох[cite: 1]
* **Аналітичні розрахунки:** DAX (Time Intelligence, CALCULATE, SUMX, Filter Contexts)[cite: 1]
* **Візуалізація:** Custom Tooltips, Bookmarks, Page Navigation, Cross-filtering, Matrix Drill-through[cite: 1]

## 📊 Ключові висновки та аналітика (Key Insights)
* **Завантаженість:** Виявлено пікові дні та години звернень пацієнтів для оптимізації графіку чергування лікарів[cite: 1].
* **Фінанси:** Визначено найбільш витратні категорії процедур та частку покриття витрат страховими компаніями[cite: 1].
* **Процеси:** Скорочення часу очікування та покращення розподілу ліжкового фонду клініки[cite: 1].
